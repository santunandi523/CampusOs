# 📚 LMS Web Application

A Learning Management System (LMS) web app designed to help users explore courses, enroll, and track their learning progress through a simple and responsive interface.

---

## 🔥 Features

- User registration and login  
- Browse available courses  
- Course enrollment system  
- Learning progress tracking  
- Responsive design for all devices  
- Admin management (future upgrade)

---

## 🛠 Tech Stack

### Frontend
- HTML  
- CSS  
- JavaScript  

*(Can be upgraded to React + Tailwind CSS)*

### Backend
- Node.js  
- Express.js  

### Database
- MongoDB
